# BGO Pipeline Workflow

On the birds eye view, the BGO pipeline consists of two steps:

- Preparation of input template files (class, individual, marker, abc atlas links): Driven by the Makefile in the `src/dendrograms` folder.
- Running the ODK pipeline to generate the ontology using the templates.

## Preparation of input template files

Classes:
- `src/patterns/data/default/CCN20250428_class_base.tsv`: Generated by template_generation_tools.py `generate_base_class_template` function
- `src/patterns/data/default/CCN20250428_class_curation.tsv`: Automatically downloaded from the curation sheet (see below)
Markers:
- `CCN20250428_evidence_marker_set.tsv`: Generated by template_generation_tools.py `generate_evidence_marker_gene_set_template` function
- `CCN20250428_marker_set.tsv`: Empty in this pipeline
- `CCN20250428_nsforest_marker_set.tsv`: Empty in this pipeline
- `CCN20250428_within_subclass_marker_set.tsv`: Empty in this pipeline

## ABC Atlas links
1. Update the kiwi URL payloads to configure the ABC Atlas links:
   - typescript/src/kiwi-payload.ts
2. To regenerate the ABC Atlas links, delete the following files:
   - src/dendrograms/CCN20230722_abc_urls.json
   - src/dendrograms/CCN20230722_abc_urls_evidence_marker_set.json
   - src/dendrograms/CCN20230722_abc_urls_marker_set.json
   - src/dendrograms/CCN20230722_abc_urls_nsforest_marker_set.json
   - src/dendrograms/CCN20230722_abc_urls_ws_marker_set.json
3. Then delete the DOSDP templates containing the ABC Atlas links:
   - src/patterns/data/default/CCN20230722_class_base.tsv
   - src/patterns/data/default/CCN20230722_evidence_marker_set.tsv
   - src/patterns/data/default/CCN20230722_marker_set.tsv
   - src/patterns/data/default/CCN20230722_nsforest_marker_set.tsv
   - src/patterns/data/default/CCN20230722_within_subclass_marker_set.tsv
4. Finally, run the following command in the `src/dendrograms` folder to regenerate the files:
```bash
make
```
